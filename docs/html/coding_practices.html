Variables

To define a variable, use the keyword 'let', followed by a Colon, a type and the name of the variable. This can either be followed by an expression to initialize the variable, or ended with a semicolon, to leave the variable un-initialized.

The following example shows defining two variables, re-assinging/modifying them and using them inside an expression


            let:int number = 10;
            let:long number2;
            number2 = number * 2
            number += 10;
