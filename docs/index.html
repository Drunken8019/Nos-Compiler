NOS Documentation

Welcome to the NOS Documentation. NOS is a low-level, statically typend and ahead-of-time compiled language. The compiler frontend is built from scratch in C++, with the backend being Assembly (NASM) and the MSVC-Linker. Here you can find everything related to the language. Important to note is, the NOS programming language was created purely as hobby-project. If you want to try it out, downloads for the compiler can be found here.
